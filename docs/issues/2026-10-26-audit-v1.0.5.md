# Audit — v1.0.5 (2026-10-26)

Scope: `main` after the published `v1.0.4` tag, including the in-flight
WhenJumpScare and preset work. This document records what was reviewed, what was
fixed, and what remains.

## Fixed

### Security / data exposure

- **Plex token leaked through session thumbnails** — `PlexClient.thumb_url()`
  returned `http://plex/...?X-Plex-Token=...`, so every browser loading
  `/api/sessions` received the admin token. It now returns a local
  `/api/plex-image?path=...` URL; the token is attached server-side. Added tests
  for the proxy URL and for absolute/protocol-relative image paths.
- **Wildcard CORS** — `allow_origins=["*"]` let any website read API responses
  from a LAN deployment. CORS is now opt-in via `CLEANPLEX_CORS_ORIGINS`
  (same-origin by default).
- **Unauthenticated webhook when Basic auth is enabled** — Plex cannot send Basic
  credentials. The receiver now returns 503 unless `CLEANPLEX_WEBHOOK_TOKEN` is
  configured whenever `CLEANPLEX_AUTH_USER/PASS` are set.

### Scanner correctness

- **A rescan deleted imported/hand-edited segments** — `scan_video()` called
  `delete_segments_for_guid()` before every scan. It now deletes only pure
  `scanner` rows (`delete_scanner_segments_for_guid`); merged rows carrying
  another source are preserved.
- **Paused/window-aborted scans were stranded** — the re-queue happened while the
  guid was still in `_current_guids`, where `enqueue()` is a no-op. Requeueing is
  deferred to the `finally` block.
- **`force_scan` could remain set forever** — a force request arriving during a
  scan left the flag set, permanently bypassing window/rating/ignore gates. The
  worker now clears it unconditionally after each job.
- **A crashed worker killed the supervisor** — `asyncio.gather()` re-raised the
  worker exception and escaped `scanner_loop`. Now uses
  `return_exceptions=True` and logs the crash.
- **640m model validation blocked the event loop** — the settings route called the
  synchronous download helper directly. It now awaits
  `_ensure_640m_model_async()` under the shared download lock.

### VideoSkip

- **Bulk `/videoskip/auto` ignored the daily ceiling** — added an atomic
  `videoskip_usage` reservation table shared by the queue and the synchronous
  bulk route. Each actual exchange attempt consumes one slot; queued jobs are
  deferred (without consuming an attempt) when the allowance is full.
- **`skipped` was terminal across policy changes** — un-ignoring a title, enabling
  auto-fetch, or changing the allowed-library list now requeues skipped rows.
- **Per-session N+1 filter lookup** — the watcher loads all user filters once per
  poll instead of one query per session.
- **Merged-source deletion** — removing a source prefix used to delete the whole
  merged row. It now strips that source and keeps the interval under a remaining
  primary source.

### WhenJumpScare (in-flight feature)

- **Unreadable metadata** now raises `WhenJumpScareError` instead of a raw JSON
  exception (which became a 500).
- **Movie-link validation** used a string prefix, so
  `whenjumpscare.com.evil.example` passed. It now requires an exact host match and
  a `/movie/` path.
- Added tests for invalid JSON, wrong-host links, and zero-count films.

### Runtime errors

- **`ParseError` undefined in `videoskip_service.py`** — automatic cut-mismatch
  rejection would have raised `NameError`. Imported.
- **`asyncio` undefined in `sync_routes.py`** — the `/test-hash` route would have
  raised `NameError`. Imported.
- **Bare `except` in `bg_jobs.py`** — narrowed to `TypeError`/`ValueError`.

### Release metadata

- `pyproject.toml`, `cleanplex/__init__.py`, FastAPI app version, the sidebar
  badge, and `frontend/package.json`/lock are now `1.0.5`.

## Remaining / deliberately not changed

- **No auth by default.** The service binds `0.0.0.0` for LAN use. Adding a
  default password or default-deny would break the Docker/port-mapping workflow;
  the supported answer is `CLEANPLEX_AUTH_USER/PASS` (documented). A future
  release could add a generated first-run credential.
- **Legacy `/api/sync/*` fan-out.** One GitHub request per file hash with a
  60/hour unauthenticated limit; the UI no longer exposes it. Remove or batch it
  before relying on it again.
- **MCF vocabulary coverage.** ~89 of ~130 specific terms are mapped; unmapped
  terms become `other`.
- **EDL severity.** EDL has no severity/category; imports are high-severity skip
  cuts. Documented in the README rather than guessed.
- **VideoSkip search pagination / series pages.** Single result page only.
- **Plex marker migration.** Still a drop/recreate for a cache table; recorded as
  an exception rather than converted to a copy+swap.

## Verification

- Backend: 579 tests pass (`pytest tests/ -q`).
- Frontend: 58 tests pass, `tsc --noEmit` clean, production build succeeds.
- CI workflows build the image, boot it, and run Playwright against the real app.
